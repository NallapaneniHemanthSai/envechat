# EnveChat Backend

This is the backend repository for **EnveChat**, a chat application. It is built using Java and Spring Boot.

## Links

- **Frontend Repository:** [https://github.com/NallapaneniHemanthSai/envechat-frontend](https://github.com/NallapaneniHemanthSai/envechat-frontend)
- **Frontend Live Deployment:** [https://envechat-frontend.vercel.app](https://envechat-frontend.vercel.app)
- **Backend Live Deployment:** [https://envechat.onrender.com](https://envechat.onrender.com)

## Technologies Used

- Java 17+ (or applicable version)
- Spring Boot
- Maven
- WebSockets (for real-time chat)
- PostgreSQL / MongoDB (depending on your setup)

## Getting Started

To run this project locally:

1. Clone the repository:
   ```bash
   git clone <your-backend-repo-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd backend
   ```
3. Run the application using Maven:
   ```bash
   ./mvnw spring-boot:run
   ```

## Deployment

The backend is configured for deployment on [Render](https://render.com/). 
The frontend is deployed on [Vercel](https://vercel.com/).
